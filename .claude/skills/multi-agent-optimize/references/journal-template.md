# 优化日志模板

每轮在 `_skill-metrics/<技能名>/journal.md` 末尾追加一段，新的在下面。

```markdown
## v7（2026-10-02）一句话标题

- **起因**：上一轮报告 `reports/xxx.html` 显示……（引用 1–2 个数字）
- **假设**：因为……所以……
- **措施**：（与 versions.json 的 measures 一致）
- **预期**：`per_unit.fix <= 1.8`；`cat.验收.avg_cost <= 300K`
- **结果**（报告 `reports/v6_vs_v7.html`，纯新单元 A n / B n）：
  | 预期 | 旧 | 新 | 是否达到 |
  |---|---|---|---|
- **归因**：哪些变化来自本次措施，哪些来自工单难度或离群单元
- **副作用**：
- **下一步**：（挂杠杆编号和预期收益）
```
