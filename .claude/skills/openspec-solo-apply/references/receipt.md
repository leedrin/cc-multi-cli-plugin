# 回执格式

每张单一个回执文件 `_solo/_receipts/T<编号>.md`。每个阶段结束时**追加**一节，不覆盖前面的节；节标题照下面原样写，续跑靠最后一节判断位置。

```
## 执行
状态：完成 / 中断
文件清单：<本轮改动和新建的全部文件>
先红：<测试名> → <修复前失败的关键 1–5 行>
验收：<命令> → 通过/失败/外部阻塞（失败时附关键报错 ≤10 行）
存疑：<没有写「无」>

## 审查          （复审写「## 复审 <轮次>」）
<编号. 严重程度｜归属｜类型｜文件:行号｜问题｜怎么改>，没有发现写「无发现」
结论：<开修复轮 <轮次> / 进验收 / 存疑：测试 <编号>…>

## 修复 <轮次>
来源：<审查/验收> 条目 <编号…>
<编号｜成立·已修（测试名）/ 不成立（证据）｜同类位置：<列表或「无」>>
先红：<每条成立的修复前失败关键行>
文件清单：…
验收：…

## 验收
<命令 → 通过/失败/外部阻塞>
越界：<通过 / 越界文件>
测试篡改：<无 / 具体位置>
结论：通过 / 不通过（失败项编号）
```

每节写完再进下一阶段。阶段做了一半被打断时，续跑从上一节的状态重来这个阶段。
