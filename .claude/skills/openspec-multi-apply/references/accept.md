# 验收派单数据

重跑命令、越界检查、修复轮核对、按路径提交和收尾步骤等固定规则在 `.claude/agents/openspec-acceptor.md`，这里不重复。派单时 `subagent_type: "openspec-acceptor"`，description 写「验收 T<编号>」，prompt 按 SKILL.md「派单格式」写：

```text
模式：验收
仓库根目录：<路径>
落盘文件：_tickets/_receipts/T<编号>-accept.md（必须写入，下游要读；不要只在最终回答里返回）
工单编号：T<编号>
工单路径：<路径>
执行回执：<T<编号>-exec.md、T<编号>b-exec.md …，按轮次顺序>
审查结论：<一行>
勾选任务：<tasks.md 任务号；可省略>
台账追加：<一行；可省略>
提交信息：<提交信息>
```

- 执行回执：列全首轮和各修复轮，验收员以它们「文件清单」的并集为本单产出。
- 审查结论：会原样写进工单记录段，如「3 条；1、2 成立 → b 已修，3 不成立：foo.ts:42 已处理」「无发现」「合并在 T001 组」。
- 勾选任务：该 openspec 任务拆出的单这次全部完成时才写，否则省略此行。
- 台账追加：分诊时拟的一行 `- <类别>｜<规则>｜出处 T<编号>`；没有就省略此行。
- 提交信息：放最后一行，含工单号和项目要求的 attribution 行。
